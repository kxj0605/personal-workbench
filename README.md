# 日程笔记

一个把个人管理与内容创作整合在一起的数字工作台。

在线体验：[https://image-notes-starter.vercel.app/](https://image-notes-starter.vercel.app/)

## 项目简介

日程笔记用于记录生活、整理任务、管理订阅，也为内容创作提供灵感收集、项目推进、脚本拆解和复盘空间。

它不是团队协作工具，而是面向个人长期使用的轻量工作台：让任务、笔记和创作过程都更清晰、更容易坚持。

## 核心功能


- **任务与日程**：用列表、日历、四象限和长期追踪管理安排。
- **笔记与公开内容**：记录私人笔记，也可选择公开分享和评论交流。
- **订阅与常用网址**：管理订阅到期信息，集中保存常用网站。
- **创作工作台**：覆盖项目、灵感视频、脚本拆解、素材和复盘。
- **个人设置**：支持昵称与工作台主题调整。

## 技术栈

- React 19
- Vite 7
- Supabase：登录、数据库与用户数据管理
- Lucide React：图标
- 原生 CSS：界面与响应式布局
- Vercel：线上部署
