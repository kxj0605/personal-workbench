三层结构体系

本系统严格按照：题材大类 (一级) → 母题 (二级) → 对标视频/版本 (三级) 组织。
账号为横向资源，可跨母题关联多条视频。删除大类或账号时，均安全保留母题与视频。

推荐研究心流路径
  1. 录入爆款视频时，若尚不明确母题，可暂存入未归类待处理池；
  2. 提炼出戏剧共性后，创建母题并提炼“故事骨架”与“情绪闭环”；
  3. 在母题详情中选中多个视频版本进行横向矩阵对比，挖掘不同创作者在 Hook、反转与结尾的差异；
  4. 提炼 S 级视频并标记为标杆案例，一键导出 Markdown 研习分析报告。
